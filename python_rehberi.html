01. Temel Veri Tipleri & Değişken Kapsamları

Python dinamik tipli (dynamically typed) ve güçlü tipli (strongly typed) bir dildir. Çalışma zamanında değişkenlerin tipi otomatik belirlenir ancak örtülü tip dönüşümlerine izin verilmez.

  • int: Sınırsız duyarlıklı tamsayılar. Bellek miktarı elverdiği sürece taşma (overflow) yaşanmaz.
  • float: IEEE 754 standardına uygun çift duyarlıklı (double precision) ondalıklı sayılar.
  • complex: Gerçel ve sanal kısımdan oluşan karmaşık sayılar. `a + bj` formatında tanımlanır.
  • str: Değiştirilemez (immutable) karakter dizileri. Dilimleme (slicing), f-string ve yerleşik metotlar içerir.
  • bool: `True` ve `False` mantıksal değerleri. Matematiksel işlemlerde `1` ve `0` gibi davranırlar.
  • NoneType: Bir değerin veya referansın yokluğunu belirten `None` sabit tipi.
  • type() & isinstance(): `type()` nesnenin tam sınıfını dönerken, `isinstance()` kalıtım hiyerarşisini de hesaba katar. Sınıf kontrolünde `isinstance()` tercih edilmelidir.
  • Değişken Kapsamları (Scopes): Local (yerel), Nonlocal (iç içe fonksiyonlar) ve Global (modül seviyesi). `global` ve `nonlocal` anahtar kelimeleriyle üst kapsamlardaki değerler değiştirilebilir.
Tip İpuçları (Type Hints): Python 3.5+'ten itibaren statik analiz araçları için tip belirtimleri desteklenir. Değişken ve argümanlara `x: int = 5` biçiminde tip ipucu verilebilir.

02. Dahili Veri Yapıları & Collections Modülü

Python verileri gruplamak için son derece esnek, optimize edilmiş dahili veri yapılarına sahiptir.

  • List (Liste): Dinamik boyutlu, sıralı ve değiştirilebilir (mutable) veri yapıları. List comprehension ile tek satırda oluşturulabilirler. `copy` ve `deepcopy` ile kopyalama yapılır.
  • Tuple (Demet): Değiştirilemez (immutable), sıralı yapılar. Hızlı veri paketleme ve unpack işlemlerinde kullanılır. `namedtuple` ile indis yerine isimle erişilebilen yapılar tanımlanır.
  • Dict (Sözlük): Anahtar-Değer (Key-Value) çiftlerinden oluşan, hash-tabanlı hızlı yapılar. Python 3.9+ ile iki sözlüğü birleştirmek için `|` ve `|=` operatörleri kullanılabilir.
  • Set & Frozenset: Eşsiz (unique) elemanlardan oluşan kümeler. Sırasızdırlar. `frozenset` değiştirilemeyen (immutable) kümedir. Küme işlemleri (kesişim, birleşim vb.) matematiksel operatörlerle hızlıca yapılır.
  • Collections Modülü: `deque` (O(1) ekleme/silme özellikli çift yönlü kuyruk), `Counter` (elemanların frekansını sayan yapı), `defaultdict` (olmayan anahtar sorgulandığında varsayılan değer dönen sözlük), `OrderedDict` (ekleme sırasını koruyan sözlük).
  • Heapq: Öncelikli kuyruk (priority queue) algoritmalarını implement eden min-heap yapısı.
  • Array Modülü: Sadece aynı türden C tipi temel verileri saklayabilen homojen, bellek dostu diziler.
Shallow Copy vs Deep Copy Tuzağı: `list.copy()` veya dilimleme `[:]` sadece birinci seviyedeki referansları kopyalar (shallow). İç içe listeler veya nesneler kopyalanırken alt elemanların referansı aynı kalır. Bunu engellemek için `copy.deepcopy()` kullanılmalıdır.

03. Operatörler & Kontrol Yapıları

Python'da ifadelerin yönetilmesi için zengin operatör kümesi ve modern kontrol mekanizmaları bulunur.

  • Temel Operatörler: Aritmetik, karşılaştırma ve mantıksal (`and`, `or`, `not`) operatörler.
  • Identity & Membership: `is` bellek adresinin eşitliğini (referans bazlı), `==` ise değerin eşitliğini kontrol eder. `in` operatörü elemanın bir koleksiyon içinde olup olmadığını sınar.
  • Walrus Operator (:=): Değişken atamasını bir ifade (expression) içinde doğrudan yapmaya imkan tanır.
  • Pattern Matching (match-case): Python 3.10 ile gelen, C'deki switch-case yapısından çok daha yetenekli yapısal desen eşleme (structural pattern matching) aracıdır. Nesnelerin tiplerini ve içeriklerini doğrudan filtreleyebilir.
  • Döngüler & Else Blokları: `for` ve `while` döngülerinin sonuna `else` bloğu eklenebilir. Eğer döngü `break` ifadesi ile sonlanmadan doğal yollarla biterse, `else` bloğu tetiklenir.

04. Fonksiyonlar & Fonksiyonel Programlama

Python fonksiyonları birinci sınıf vatandaştır (first-class citizens); yani değişkenlere atanabilir, başka fonksiyonlara parametre olarak geçilebilir veya geri döndürülebilirler.

  • Esnek Argümanlar: `*args` konumsal parametreleri bir `tuple` olarak, `**kwargs` ise isimlendirilmiş parametreleri bir `dict` olarak toplar.
  • Function Annotations: Fonksiyon parametreleri ve dönüş tipleri için ek açıklamalar sağlar.
  • Closure: İç içe fonksiyonlarda (nested functions), içteki fonksiyonun dıştaki fonksiyonun değişken kapsamını (kendi çalışması bitse bile) bellekte saklaması durumudur.
  • Decorators: Bir fonksiyonun davranışını, onun kodunu değiştirmeden sarmallayıp genişleten fonksiyonlardır.
  • Generators: `yield` kullanarak veriyi tek seferde üretip hafızaya almak yerine, her çağrıldığında üreten ve durumu (state) koruyan yapılardır.
  • functools.partial: Bir fonksiyonun belirli parametrelerini önceden bağlayarak daha az parametreli yeni bir fonksiyon üretir.
Mutable Default Argument Hatası: Varsayılan parametre olarak mutable (değiştirilebilir) nesneler (örneğin liste `[]` veya sözlük `{}`) verilmemelidir. Varsayılan argümanlar fonksiyon tanımlandığı anda bir kez oluşturulur ve sonraki çağrılarda paylaşılır. Çözüm olarak `None` kullanılmalıdır.

05. Nesne Yönelimli Programlama (OOP)

Python tamamen nesneye yönelik bir dildir. Tüm yapılar, fonksiyonlar ve temel tipler dahil birer nesnedir.

  • Kapsülleme (Encapsulation): `_deger` protected özelliğidir (yazılımcı anlaşmasıyla dışarıdan dokunulmamalıdır). `__deger` ise private özelliğidir; Python arkada Name Mangling uygulayarak bu niteliği `_SinifAdi__deger` şekline dönüştürür ve doğrudan erişimi zorlaştırır.
  • Çoklu Kalıtım (Multiple Inheritance) & MRO: Python birden fazla sınıftan türemeyi destekler. Metotların aranma sırası C3 Lineerleştirme algoritmasıyla belirlenen **MRO (Method Resolution Order)** sırasına göredir. `super()` bu sırayı takip eder.
  • Özellik Yöneticileri: `@property` (getter), `@özellik.setter` (setter) ve `@classmethod` (sınıf seviyesinde işlem), `@staticmethod` (sınıftan bağımsız yardımcı fonksiyon).
  • Magic (Dunder) Metotlar: Çift alt tire (`__`) ile çevrili metotlar. Nesnelere aritmetik işlemler (`__add__`), uzunluk sorguları (`__len__`), indeks erişimleri (`__getitem__`), nesnenin fonksiyon gibi çağrılması (`__call__`) gibi yetenekler kazandırır.
  • __slots__: Sınıfta dinamik olarak nitelik (attribute) atanmasını devre dışı bırakarak nesnelerin yalnızca belirtilen nitelikleri saklamasını sağlar. Bu da bellek kullanımını ciddi oranda düşürür.
  • Dataclasses (Python 3.7+): `@dataclass` dekoratörü otomatik olarak `__init__`, `__repr__`, `__eq__` gibi standart dunder metotlarını üreterek boilerplate kodları engeller.

from abc import ABC, abstractmethod
from dataclasses import dataclass

# 1. Abstraction (Soyutlama)
class Arac(ABC):
    @abstractmethod
    def calis(self):
        pass

# 2. Kalıtım ve Encapsulation
class Otomobil(Arac):
    def __init__(self, marka, hiz):
        self.marka = marka          # Public
        self._hiz = hiz             # Protected
        self.__motor = "V8"         # Private (Name Mangling uygulanır)

    def calis(self):
        return f"{self.marka} motoru çalıştı."

    # @property ve Setter kullanımı
    @property
    def hiz(self):
        return self._hiz

    @hiz.setter
    def hiz(self, yeni_hiz):
        if yeni_hiz >= 0:
            self._hiz = yeni_hiz

# 3. Magic Metotlar ve __slots__ Optimizasyonu
class Nokta:
    # Sadece x ve y hafızada yer tutar, __dict__ oluşturulmaz
    __slots__ = ["x", "y"]
    
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Nokta({self.x}, {self.y})"

    def __add__(self, diger):
        return Nokta(self.x + diger.x, self.y + diger.y)

    def __eq__(self, diger):
        return self.x == diger.x and self.y == diger.y

    fiyat: float

06. Sınıf Bağlantıları & Tasarım Desenleri

Sınıflar arasındaki ilişkilerin doğru modellenmesi, kodun esnekliği, sürdürülebilirliği ve test edilebilirliği açısından kritiktir.

  • Composition (Kompozisyon): "Has-a" (sahip olma) ilişkisidir. Parça nesnelerin ömrü bütünleşik nesnenin ömrüne bağlıdır. (örn: Bilgisayar kapandığında işlemcinin de nesne ömrü biter).
  • Aggregation (Kümeleme): Daha zayıf bir ilişkidir. Nesnelerin yaşam süreleri bağımsızdır. (örn: Kütüphane nesnesi silinse bile kitap nesneleri var olmaya devam eder).
  • Dependency Injection (Bağımlılık Enjeksiyonu): Bir sınıfın bağımlı olduğu diğer nesneleri kendi içinde oluşturması yerine, bu bağımlılıkların dışarıdan verilmesidir.
  • Singleton Desen: Bir sınıftan çalışma süresi boyunca yalnızca tek bir örnek (instance) üretilmesini güvenceye alır. Metaclass'lar ile temiz bir şekilde uygulanabilir.
  • Factory Desen: Nesne oluşturma mantığını istemciden gizleyerek, tek bir arayüz üzerinden dinamik nesne üretimi yapılmasını sağlar.

# 1. Composition vs Aggregation
class Motor:
    def __init__(self, guc):
        self.guc = guc

class Araba: # Composition: Motor'u kendi içinde üretir.
    def __init__(self, marka, guc):
        self.marka = marka
        self.motor = Motor(guc) 

class Ogretmen:
    def __init__(self, isim):
        self.isim = isim

class Okul: # Aggregation: Ogretmen dışarıdan verilir, okul yok olsa da öğretmen kalır.
    def __init__(self, isim, ogretmenler=None):
        self.isim = isim
        self.ogretmenler = ogretmenler or []

# 2. Dependency Injection
class VeritabaniServisi:
    def veri_cek(self):
        return "Ham Veri"

class Raporlayici:
    def __init__(self, db_servis: VeritabaniServisi): # Servis dışarıdan enjekte edilir
        self.db = db_servis
        
    def rapor_hazirla(self):
        veri = self.db.veri_cek()
        return f"Rapor: {veri}"

# 3. Singleton (Metaclass yöntemiyle)
class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class SistemAyarlari(metaclass=SingletonMeta):
    def __init__(self):
        self.veritabani_yolu = "/var/db/app.sqlite"

# 4. Factory Deseni
class PDFRapor:
    def olustur(self): return "PDF Rapor Dosyası"

class ExcelRapor:
    def olustur(self): return "Excel Tablo Dosyası"

class RaporFabrikasi:
    @staticmethod
    def rapor_olustur(tip):
        harita = {"pdf": PDFRapor, "excel": ExcelRapor}
        sınıf = harita.get(tip.lower())
        if sınıf:
            return sınıf()
        raise ValueError(f"Bilinmeyen rapor tipi: {tip}")

07. Hata Yönetimi (Exception Handling)

Python'da hatalar birer nesnedir ve tüm istisnalar `BaseException` hiyerarşisinden türetilmiştir. Programın kontrolünü kaybetmeden hataları yönetmek için `try-except-else-finally` blokları kullanılır.

  • Blokların Görevleri: `try` riskli kodları, `except` yakalanacak hataları belirtir. `else` hata oluşmazsa çalışır, `finally` ise hata oluşsa da oluşmasa da (kaynak kapatma vb. işlemler için) mutlaka çalışır.
  • Hata Zincirleme (raise ... from): Bir hatayı yakalayıp başka bir hata fırlatırken orijinal hatanın izini (traceback) kaybetmemek için kullanılır.
  • LBYL vs EAFP:
    • LBYL (Look Before You Leap): Eylemden önce her şeyi kontrol etme tarzı (örn: `if os.path.exists(f):`).
    • EAFP (Easier to Ask Forgiveness than Permission): Python topluluğunda önerilen tarz; önce işlemi yapmaya çalış, hata alırsan yakala (örn: `try/except`). Daha hızlı ve okunabilirdir.

08. Bellek Yönetimi & Garbage Collector

Python otomatik bellek yönetimi (automatic memory management) yapar. Ana mekanizması **Referans Sayımı (Reference Counting)** sistemidir. Her nesnenin kaç farklı değişken tarafından işaret edildiği sayılır. Sayı `0` olduğunda nesne bellekten derhal silinir.

  • Dairesel Referans (Circular Reference): A nesnesi B'yi, B de A'yı referans gösteriyorsa referans sayıları asla `0` olmaz. Bu sızıntıyı çözmek için **Garbage Collector (gc modülü)** arka planda çalışıp dairesel referansları tespit eder ve bellekten temizler.
  • Weakref (Zayıf Referanslar): Referans sayacını artırmadan bir nesneye ulaşmayı sağlar. Cache mekanizmalarında veya dairesel referansların oluşmasını engellemek amacıyla kullanılır.
  • tracemalloc: Bellekte en çok yer kaplayan satırları tespit etmemizi sağlayan yerleşik modüldür.

10. Veritabanı Programlama (SQL & SQLite)

Python standart olarak `sqlite3` motoru ile birlikte gelir. PostgreSQL (`psycopg2`) ve MySQL (`mysql-connector-python`) gibi ilişkisel veritabanı sürücüleri de sqlite3 modülü ile oldukça benzer bir API yapısı (PEP 249 - Python Database API Specification v2.0) kullanır.

  • SQL Injection: Kullanıcıdan gelen değişkenleri SQL string'inin içine doğrudan yazmak (string formatlama ile) büyük güvenlik açığı oluşturur. Değerler sorguya her zaman parametre olarak geçilmelidir.

  • Context Manager: Connection nesnesi context manager olarak kullanıldığında hata durumunda otomatik `rollback()`, başarı durumunda otomatik `commit()` yapar. Ancak cursor'ların kapatılmasını sağlamaz, bu yüzden cursor için ayrı bir context manager kullanılmalıdır.

11. Generators & Iterators (Yineleyiciler)

Python'da nesnelerin `for` döngüsünde kullanılabilmesini sağlayan sisteme **Iterator Protocol (Yineleyici Protokolü)** denir.

  • Iterator: Bir nesnenin iterable olması için `__iter__` metoduna sahip olması ve bu metodun `__next__` metodunu uygulayan bir nesne dönmesi gerekir. Veri bittiğinde `StopIteration` hatası fırlatılır.
  • Generator: Iterator oluşturmanın kolay yoludur. `yield` anahtar kelimesiyle veriyi parça parça dışarıya iletir, her çağrıldığında kaldığı yeri ve değişken durumlarını hafızada tutarak devam eder.
  • itertools: Sonsuz döngüler, permütasyonlar, kombinasyonlar ve gruplama gibi gelişmiş yineleme işlemleri için optimize edilmiş C tabanlı bir standart kütüphanedir.

13. Bağlam Yöneticileri (Context Managers)

`with` anahtar kelimesiyle kullanılan bağlam yöneticileri, açılan kaynakların (dosya, network, veritabanı kilitleri) hata alınsa dahi güvenli bir şekilde kapatılmasını veya temizlenmesini garanti eder.

  • Protokol Metotları: Nesne `with` bloğuna girdiğinde `__enter__` çalışır. Bloktan çıkıldığında `__exit__` tetiklenir.
  • Hata Yönetimi: `__exit__(self, exc_type, exc_val, exc_tb)` metodu parametrelerinde oluşan hatayı alır. Eğer bu metot `True` döndürürse oluşan hata yutulur ve program durmadan devam eder. `False` veya hiçbir şey dönmezse hata normal şekilde yukarı fırlatılır.
  • contextlib Modülü: `@contextmanager` dekoratörü yardımıyla, sınıf yazmaya gerek kalmadan bir generator fonksiyonu (`yield` kullanarak) üzerinden kolayca context manager tanımlanabilir.

14. Multithreading, Multiprocessing & Asyncio

Python'da eşzamanlılık (concurrency) ve paralellik (parallelism) üç farklı yaklaşımla ele alınır.

  • GIL (Global Interpreter Lock): CPython yorumlayıcısının, thread emniyeti (thread safety) sağlamak amacıyla aynı anda yalnızca tek bir yerel thread'in Python bytecode çalıştırmasına izin veren mekanizmasıdır. Bu yüzden **Multithreading** CPU-bound (yoğun işlemci gücü gerektiren) işlemlerde paralellik sağlamaz, sadece I/O-bound (dosya okuma, ağ isteği bekleme) işlerinde etkilidir.
  • Multiprocessing: GIL engelini aşmak için ayrı işletim sistemi süreçleri (processes) oluşturur. Her sürecin kendi bellek alanı ve yorumlayıcısı vardır. CPU-bound işler için idealdir ancak süreçler arası veri transferi (IPC) maliyetlidir.
  • Asyncio: Tek bir thread ve süreç üzerinde, asenkron G/Ç (I/O) işlemlerinin **Event Loop (Olay Döngüsü)** yardımıyla işbirliği içinde (cooperative multitasking) yürütülmesini sağlar. CPU kilitlenmesi yaşatmayan binlerce eşzamanlı ağ bağlantısı için mükemmeldir.
Race Condition ve Eşzamanlılık Çakışmaları: Ortak bellek alanına sahip Threading işlemlerinde, birden fazla thread aynı anda bir değişkeni güncellemeye çalışırsa veri kaybı (race condition) yaşanır. Bunu önlemek için `threading.Lock()` nesneleri kullanılmalıdır.

17. Düzenli İfadeler (Regular Expressions - re)

Python yerleşik `re` modülü üzerinden karmaşık metin arama, doğrulama, yakalama ve değiştirme işlemlerini gerçekleştirmek için düzenli ifadeleri destekler.

25. Yerleşik Fonksiyonlar (Built-in Functions)

  • eval() & exec(): Dinamik kod çalıştırma araçlarıdır. String halindeki kodları yürütürler. Güvenlik açığı yaratabileceği için kullanıcı girdisiyle asla kullanılmamalıdır.

from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel, Field
from typing import Optional

app = FastAPI(title="Ürün API", version="1.0")

# Pydantic şemaları (otomatik doğrulama)
class UrunOlustur(BaseModel):
    isim: str = Field(..., min_length=1, max_length=100)
    fiyat: float = Field(..., gt=0, description="Sıfırdan büyük olmalı")
    stok: int = Field(default=0, ge=0)
    kategori: Optional[str] = None

class UrunYanit(UrunOlustur):
    id: int

# Bellek içi depo (demo amaçlı)
urunler: dict[int, dict] = {}
sayac = 0

@app.post("/urunler", response_model=UrunYanit, status_code=201)
async def urun_olustur(urun: UrunOlustur):
    global sayac
    sayac += 1
    urun_dict = {"id": sayac, **urun.model_dump()}
    urunler[sayac] = urun_dict
    return urun_dict

@app.get("/urunler")
async def urun_listele(
    kategori: Optional[str] = Query(None, description="Kategoriye göre filtrele"),
    limit: int = Query(10, ge=1, le=100)
):
    sonuclar = list(urunler.values())
    if kategori:
        sonuclar = [u for u in sonuclar if u.get("kategori") == kategori]
    return sonuclar[:limit]

@app.get("/urunler/{urun_id}", response_model=UrunYanit)
async def urun_getir(urun_id: int):
    if urun_id not in urunler:
        raise HTTPException(status_code=404, detail="Ürün bulunamadı")
    return urunler[urun_id]

from typing import Optional
from datetime import datetime

    sehir: str
    posta_kodu: str = Field(..., pattern=r"^\d{5}$")

class Kullanici(BaseModel):
    id: int
    isim: str = Field(..., min_length=2, max_length=50)
    eposta: str
    yas: int = Field(default=18, ge=0, le=150)
    adres: Optional[Adres] = None
    kayit_tarihi: datetime = Field(default_factory=datetime.now)

    # Özel alan doğrulayıcı
    @field_validator("eposta")
    @classmethod
    def eposta_kontrol(cls, v):

            raise ValueError("Geçerli bir e-posta adresi giriniz")

    def yas_kontrol(self):
        if self.yas < 13:
            raise ValueError("Kullanıcı 13 yaşından büyük olmalı")
        return self

34. Ağ (Socket) Programlama

Flask veya FastAPI gibi yüksek seviye web araçları arka planda soketlerle iletişim kurar. Python'ın socket modülü ile doğrudan işletim sistemi seviyesinde TCP/UDP bağlantıları kurabilir, kendi web sunucunuzu sıfırdan yazabilirsiniz.

🔌 34.1 — Basit TCP İstemcisi (Client)

tcp_client.py
import socket

# 1. AF_INET (IPv4), SOCK_STREAM (TCP) soketi oluştur
istemci = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. Google'ın 80 (HTTP) portuna bağlan
istemci.connect(('www.google.com', 80))

# 3. HTTP GET isteği gönder (Veriler bayt (b"") olarak gönderilir)
istemci.sendall(b"GET / HTTP/1.1\\r\\nHost: www.google.com\\r\\n\\r\\n")

# 4. Yanıtı al (En fazla 4096 bayt oku)
yanit = istemci.recv(4096)
print(yanit.decode('utf-8'))

# 5. Bağlantıyı kapat
istemci.close()

📡 34.2 — Basit TCP Sunucusu (Server)

tcp_server.py
import socket

sunucu = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
# Port kullanımda hatasını önlemek için (SO_REUSEADDR)
sunucu.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

# '0.0.0.0' tüm IP'lerden gelen bağlantılara açık, 9999 ise port
sunucu.bind(('0.0.0.0', 9999))
sunucu.listen(5) # Maksimum 5 bağlantıyı beklet

print("Sunucu 9999 portunda dinliyor...")

while True:
    # İstemci bağlandığında kabul et
    istemci_soketi, adres = sunucu.accept()
    print(f"Bağlantı geldi: {adres}")
    
    # İstemciye merhaba mesajı gönder
    istemci_soketi.sendall(b"Sunucudan Merhaba! Baglantiniz basarili.\\n")
    istemci_soketi.close()

35. Sürekli Entegrasyon (CI/CD - GitHub Actions)

Profesyonel Python projelerinde kod kalitesini (linting) ve doğruluğunu (testing) her bir değişiklikte otomatik olarak kontrol etmek standart bir süreçtir. GitHub Actions bu işlemleri otomatikleştirmenin en popüler yoludur.

🤖 35.1 — Otomatik Test ve Linting Pipeline'ı

Aşağıdaki konfigürasyon dosyası (.github/workflows/python-app.yml), projenize her push yapıldığında veya Pull Request açıldığında kodunuzu otomatik olarak test eder.

python-app.yml
name: Python Uygulamasi CI

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.9", "3.10", "3.11"]

    steps:
    - uses: actions/checkout@v3
    
    - name: Python ${{ matrix.python-version }} kurulumu
      uses: actions/setup-python@v3
      with:
        python-version: ${{ matrix.python-version }}
        
    - name: Bagimliliklari yukle
      run: |
        python -m pip install --upgrade pip
        pip install flake8 pytest
        if [ -f requirements.txt ]; then pip install -r requirements.txt; fi
        
    - name: Flake8 ile kod standartlarini denetle (Linting)
      run: |
        # syntax hatalari veya tanimsiz isimler varsa sureci durdur
        flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
        # uyari niteligindeki satirlar
        flake8 . --count --exit-zero --max-complexity=10 --max-line-length=127 --statistics
        
    - name: Pytest ile birim testleri (Unit Tests) calistir
      run: |
        pytest
