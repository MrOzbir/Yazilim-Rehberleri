Sussurro Kullanım Rehberi

Tamamen offline çalışan açık kaynaklı speech-to-text aracı • macOS

Sussurro Nedir?

Sussurro (İtalyanca'da "fısıltı" anlamına gelir), konuşmanı temiz, biçimlendirilmiş ve bağlama duyarlı metne dönüştüren, tamamen yerel (offline) çalışan açık kaynaklı bir ses-metin sistemidir. Temel işlevi şu şekilde özetlenebilir: mikrofona konuşursun, Sussurro metni işler ve o an aktif olan uygulamaya doğrudan yazar.

Çift Katmanlı AI Mimarisi

  • ▸ Whisper.cpp — OpenAI'nin Whisper modelinin C++ ile yeniden yazılmış, son derece optimize edilmiş versiyonu. Sesi metne bu motor dönüştürür.
  • ▸ Qwen 3 Sussurro — Projenin geliştiricisi tarafından ince ayar yapılmış bir dil modeli. Ham transkripsiyonu alır, dolgu kelimelerini temizler, kendini düzeltmeleri düzenler ve cümleleri okunabilir hale getirir.
ℹ️ Bu iki aşamalı mimari sayesinde çıktı, ham bir transkripsiyon yerine neredeyse yazı diline yakın bir metin olur. Konuşma dili bozuklukları, tereddütler ve dolgu sesleri otomatik olarak giderilir.

Kurulum (macOS)
1
Sussurro'yu indirin — aşağıdaki komutu Terminal'e yapıştırın:
Terminal 
# İndirme klasörüne geç
cd ~/Downloads

# Kurulum scriptini çalıştır
curl -fsSL https://raw.githubusercontent.com/cesp99/sussurro/master/scripts/install.sh | bash
2
İndirilen dosyaları kontrol edin:
Terminal 
ls -la ~/Downloads/sussurro-macos-arm64
3
Güvenlik iznini kaldırın — macOS bilinmeyen kaynaklara izin vermek için bu adım gereklidir:
Terminal 
cd ~/Downloads/sussurro-macos-arm64
xattr -d com.apple.quarantine sussurro
⚠️ Alternatif yöntem: Finder'da dosyayı sağ tıklayın → Aç → Aç seçeneğini seçin. Sistem uyarısı gelirse "Yine de Aç" deyin.
4
Programı başlatın ve model seçin:
Terminal 
./sussurro
Terminal çıktısı (örnek)

[2] Whisper Large v3 Turbo (1.62 GB) — yüksek doğruluk

Ses Dosyası Transkripsiyonu
1
Transcribe aracını kurun (bir kez yapılır):
Terminal 
curl -fsSL https://raw.githubusercontent.com/cesp99/sussurro/master/scripts/install-transcribe.sh | bash
2
Kurulum kontrolü:
Terminal 
which sussurro-transcribe
3
Temel transkripsiyon:
Basit kullanım 
sussurro-transcribe -i "dosya.mp3" -o "cikti.txt"
Türkçe dil seçimi 
sussurro-transcribe -i "dosya.mp3" -lang tr -o "cikti.txt"
Dolgu kelimelerini temizle (-clean) 
sussurro-transcribe -i "dosya.mp3" -lang tr -clean -o "cikti.txt"
Large v3 Turbo + Türkçe + temizle (önerilen) 
sussurro-transcribe -i "dosya.mp3" \
  -model large-v3-turbo \
  -lang tr \
  -clean \
  -o "cikti.txt"
💡 Dosya yolunu bilmiyorsanız: terminale sussurro-transcribe -i yazdıktan sonra MP3 dosyasını Finder'dan terminale sürükleyip bırakın. Yol otomatik yapışır.
Zaman damgalı çıktı 
sussurro-transcribe -i "dosya.mp3" -lang tr -timestamps -o "zamanli.txt"
Konuşmacı ayırt etme (toplantı kaydı için) 
sussurro-transcribe -i "toplanti.mp3" -diarize -lang tr -o "konusmacili.txt"
Tüm parametreleri görüntüle 
sussurro-transcribe --help

100 Dakikalık Dosyalar İçin Optimize Komut
⚠️ Uzun dosyalarda Mac'i prize takın. Large v3 Turbo modeli M1/M2/M3 donanım hızlandırmasını kullanır — arka plan uygulamalarını kapatın.
Önerilen komut — 100 dk dosya için 
sussurro-transcribe -i "uzun_dosya.mp3" \
  -model large-v3-turbo \
  -lang tr \
  -clean \
  -timestamps \
  -o "transkript.txt"
ParametreNe İşe Yarar?
-model large-v3-turboEn yüksek doğruluk, M-serisi Apple Silicon'da hızlı
-lang trDil tahmini yerine doğrudan Türkçe seç → daha hızlı
-clean"Yani", "şey", "uh" gibi dolgu kelimeleri LLM ile temizler
-timestampsHer cümlenin başına 00:04:32 formatında zaman damgası ekler
Yüksek hassasiyet modu (daha yavaş ama daha doğru) 
sussurro-transcribe -i "dosya.mp3" \
  -model large-v3-turbo \
  -lang tr -clean \
  -beam-size 5 -best-of 5 \
  -o "cikti.txt"
Toplu İşlem (Batch Processing)
Mevcut klasördeki tüm MP3'leri çevir 
for file in *.mp3; do
  sussurro-transcribe -i "$file" -lang tr -clean -o "${file%.mp3}.txt"
done
ℹ️ Bu komut, mevcut klasördeki her .mp3 dosyası için aynı isimde bir .txt oluşturur. Örn: toplanti.mp3 → toplanti.txt
Belirli bir klasördeki tüm dosyaları çevir 
find ~/Desktop/sesler -name "*.mp3" \
  -exec sussurro-transcribe -i {} -lang tr -clean -o {}.txt \;
M4A ve WAV dahil tüm formatları çevir 
for file in *.mp3 *.wav *.m4a; do
  [ -f "$file" ] || continue
  sussurro-transcribe -i "$file" -lang tr -clean -o "${file%.*}.txt"
done
