OOP (Nesne Yönelimli Programlama)

Encapsulation (Kapsülleme)

Veriyi private alan olarak gizleyip yalnızca kontrollü getter/setter metotlarıyla erişime açmaktır. Data hiding sayesinde nesnenin iç durumu korunur; dışarıdan doğrudan müdahale engellenir.

Getter / Setter

Alanı okuma ve yazma işlemlerini ayrı metotlarla kısıtlar. Validation (doğrulama) mantığı setter içine gömülür.

Data Hiding

private alan dışarıdan görünmez. Sınıf içi değişiklikler API'yi bozmaz; güvenli refactor imkânı sağlar.

JAVA private field + getter/setter + validation 
public class BankaHesabi {

    // ── private: dışarıdan doğrudan erişim KAPALI ───
    private String hesapNo;
    private double bakiye;
    private String sahibi;

    public BankaHesabi(String hesapNo, String sahibi, double baslangicBakiye) {
        this.hesapNo = hesapNo;
        this.sahibi  = sahibi;
        setBakiye(baslangicBakiye);  // setter üzerinden validation
    }

    // ── Getter: salt okunur erişim ───────────────────
    public String getHesapNo()  { return hesapNo; }
    public String getSahibi()   { return sahibi; }
    public double getBakiye()   { return bakiye; }

    // ── Setter: validation gömülü ────────────────────
    public void setBakiye(double bakiye) {
        if (bakiye < 0)
            throw new IllegalArgumentException("Bakiye negatif olamaz!");
        this.bakiye = bakiye;
    }

    // ── hesapNo immutable: setter yok ────────────────
    public void para_yatir(double miktar) {
        if (miktar <= 0) throw new IllegalArgumentException("Miktar pozitif olmalı");
        bakiye += miktar;
    }

    public static void main(String[] args) {
        BankaHesabi h = new BankaHesabi("TR123", "Ali", 1000.0);
        // h.bakiye = -500;  ← DERLEME HATASI! private
        h.para_yatir(250);
        System.out.println(h.getBakiye());  // 1250.0
    }
}
Inheritance (Kalıtım)

extends anahtar kelimesiyle bir sınıf başka bir sınıfın özelliklerini miras alır. super ile üst sınıf constructor/metoduna erişilir; method overriding ile davranış özelleştirilir.

ℹ

Constructor zinciri: Alt sınıf constructor'ı her zaman üst sınıf constructor'ını çağırmalıdır. Açıkça super(...) yazılmazsa Java otomatik olarak super() (parametresiz) çağırır.

// ── Üst sınıf (Parent) ──────────────────────────
public class Hayvan {
    protected String isim;
    protected int    yas;

    public Hayvan(String isim, int yas) {
        this.isim = isim;
        this.yas  = yas;
        System.out.println("Hayvan oluşturuldu: " + isim);
    }

    public String sesCikar() {
        return "...";
    }

    public String bilgi() {
        return isim + " (" + yas + " yaş)";
    }
}

// ── Alt sınıf (Child) ────────────────────────────
public class Kopek extends Hayvan {
    private String cins;

    // Constructor chaining: super() ile parent'ı çağır
    public Kopek(String isim, int yas, String cins) {
        super(isim, yas);  // parent constructor – ilk satır olmak ZORUNDA
        this.cins = cins;
        System.out.println("Köpek oluşturuldu: " + cins);
    }

    // @Override: derleme zamanı doğrulama annotation'ı
    @Override
    public String sesCikar() {
        return "Hav hav!";
    }

    @Override
    public String bilgi() {
        return super.bilgi() + " - Cins: " + cins;  // super ile genişlet
    }
}

// ── Test ─────────────────────────────────────────
Kopek k = new Kopek("Karabaş", 3, "Golden");
// Çıktı:
// Hayvan oluşturuldu: Karabaş
// Köpek oluşturuldu: Golden

System.out.println(k.bilgi());     // Karabaş (3 yaş) - Cins: Golden

public class Hesaplama {

// Abstract class: instantiate edilemez
public abstract class Sekil {
    protected String renk;

    public Sekil(String renk) { this.renk = renk; }

    // Alt sınıflar MUTLAKA uygulamalı
    public abstract double alan();
    public abstract double cevre();

    // Ortak concrete metot: tüm alt sınıflar kullanabilir
    public void bilgiYazdir() {
        System.out.printf("%s | Alan: %.2f | Çevre: %.2f%n",
            renk, alan(), cevre());
    }
}

public class Daire extends Sekil {
    private double yaricap;
    public Daire(String renk, double yaricap) {
        super(renk);
        this.yaricap = yaricap;
    }
    @Override public double alan()  { return Math.PI * yaricap * yaricap; }
    @Override public double cevre() { return 2 * Math.PI * yaricap; }
}

// Sekil s = new Sekil("kırmızı"); ← HATA! abstract

Java'da her sınıf dolaylı olarak Object'ten türer. toString, equals ve hashCode override edilmesi beklenen temel metotlardır.

⚠

equals / hashCode sözleşmesi: equals() override edildiğinde hashCode() da override edilmelidir. Aksi takdirde HashMap/HashSet gibi hash tabanlı yapılar hatalı çalışır.

JAVA toString · equals · hashCode override 
import java.util.Objects;

public class Nokta {
    private final int x, y;

    public Nokta(int x, int y) { this.x = x; this.y = y; }

    // toString: nesneyi String'e dönüştürür
    @Override
    public String toString() {
        return "Nokta(" + x + ", " + y + ")";
    }

    // equals: içerik eşitliği (referans değil)
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;            // aynı referans
        if (!(o instanceof Nokta)) return false; // tip kontrolü
        Nokta diger = (Nokta) o;
        return this.x == diger.x && this.y == diger.y;
    }

    // hashCode: equals ile tutarlı olmalı
    @Override
    public int hashCode() {
        return Objects.hash(x, y);  // x ve y'ye göre hash üretir
    }

    public static void main(String[] args) {
        Nokta a = new Nokta(3, 5);
        Nokta b = new Nokta(3, 5);
        Nokta c = new Nokta(1, 2);

        System.out.println(a);                    // Nokta(3, 5) – toString
        System.out.println(a.equals(b));           // true
        System.out.println(a.equals(c));           // false
        System.out.println(a.hashCode() == b.hashCode());  // true

        // HashMap'te equals+hashCode birlikte çalışır
        Map<Nokta, String> harita = new java.util.HashMap<>();
        harita.put(a, "Merkez");
        System.out.println(harita.get(b));        // "Merkez" – b ile bulunur!
    }
}

import java.io.*;
import java.net.*;

public static String get(String urlStr) throws IOException {
    HttpURLConnection conn = null;
    try {
        URL url = new URI(urlStr).toURL();
        conn = (HttpURLConnection) url.openConnection();

        conn.setRequestMethod("GET");
        conn.setConnectTimeout(5_000);   // 5 sn bağlantı timeout
        conn.setReadTimeout(10_000);    // 10 sn okuma timeout
        conn.setRequestProperty("Accept", "application/json");

        int status = conn.getResponseCode();
        if (status != HttpURLConnection.HTTP_OK) {
            throw new IOException("HTTP hata kodu: " + status);
        }

        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(conn.getInputStream()))) {
            StringBuilder sb = new StringBuilder();
            String satir;
            while ((satir = br.readLine()) != null) sb.append(satir);
            return sb.toString();
        }
    } catch (SocketTimeoutException e) {
        throw new IOException("İstek zaman aşımına uğradı", e);
    } finally {
        if (conn != null) conn.disconnect();
    }
}

public static String post(String urlStr, String jsonBody) throws IOException {
    HttpURLConnection conn = (HttpURLConnection)
        new URI(urlStr).toURL().openConnection();

    conn.setRequestMethod("POST");
    conn.setDoOutput(true);              // body yazmak için zorunlu
    conn.setConnectTimeout(5_000);
    conn.setReadTimeout(10_000);
    conn.setRequestProperty("Content-Type", "application/json");
    conn.setRequestProperty("Accept",       "application/json");

    // Request body yaz
    try (OutputStream os = conn.getOutputStream()) {
        os.write(jsonBody.getBytes("UTF-8"));
    }

    int status = conn.getResponseCode();
    InputStream is = (status < 400)
        ? conn.getInputStream()
        : conn.getErrorStream();     // 4xx/5xx → errorStream

    try (BufferedReader br = new BufferedReader(new InputStreamReader(is))) {
        StringBuilder sb = new StringBuilder();
        String satir;
        while ((satir = br.readLine()) != null) sb.append(satir);
        return sb.toString();
    } finally {
        conn.disconnect();
    }
}

public static void transfer(int gonderen, int alici, double miktar)
        throws SQLException {

    Connection conn = null;
    try {
        conn = DriverManager.getConnection(URL, USER, PASS);
        conn.setAutoCommit(false);   // ← auto-commit kapat

        // 1. Gönderenden düş
        try (PreparedStatement ps1 = conn.prepareStatement(
                "UPDATE hesaplar SET bakiye = bakiye - ? WHERE id = ?")) {
            ps1.setDouble(1, miktar);
            ps1.setInt(2, gonderen);
            ps1.executeUpdate();
        }

        // 2. Alıcıya ekle
        try (PreparedStatement ps2 = conn.prepareStatement(
                "UPDATE hesaplar SET bakiye = bakiye + ? WHERE id = ?")) {
            ps2.setDouble(1, miktar);
            ps2.setInt(2, alici);
            ps2.executeUpdate();
        }

        conn.commit();  // ← İKİSİ DE başarılı → kaydet
        System.out.println("Transfer başarılı");

    } catch (SQLException e) {
        if (conn != null) {
            try { conn.rollback(); } // ← geri al
            catch (SQLException rb) { rb.printStackTrace(); }
        }
        throw e;
    } finally {
        if (conn != null)
            try { conn.close(); }
            catch (SQLException e) { e.printStackTrace(); }
    }
}

wait / notify — Producer-Consumer

wait(), notify() ve notifyAll() yalnızca synchronized blok içinde çağrılabilir; aksi takdirde IllegalMonitorStateException fırlatılır. Modern kod için BlockingQueue daha güvenli bir alternatiftir.

JAVA wait/notify ile basit Producer-Consumer 
class OrtakKuyruk {
    private final Queue<Integer> kuyruk = new LinkedList<>();
    private final int KAPASITE = 5;

    // Producer: üret ve ekle
    public synchronized void uret(int deger) throws InterruptedException {
        while (kuyruk.size() == KAPASITE) {
            System.out.println("Kuyruk dolu, producer bekliyor...");
            wait();  // lock bırak + bekle (if değil while: spurious wakeup)
        }
        kuyruk.add(deger);
        System.out.println("Üretildi: " + deger + " | Boyut: " + kuyruk.size());
        notifyAll();  // bekleyen consumer'ları uyandır
    }

    // Consumer: al ve işle
    public synchronized int tuket() throws InterruptedException {
        while (kuyruk.isEmpty()) {
            System.out.println("Kuyruk boş, consumer bekliyor...");
            wait();
        }
        int deger = kuyruk.poll();
        System.out.println("Tüketildi: " + deger);
        notifyAll();  // bekleyen producer'ları uyandır
        return deger;
    }
}

// ── Kullanım ─────────────────────────────────────
OrtakKuyruk pq = new OrtakKuyruk();

Thread producer = new Thread(() -> {
    for (int i = 1; i <= 8; i++) {
        try { pq.uret(i); Thread.sleep(100); }
        catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}, "Producer");

Thread consumer = new Thread(() -> {
    for (int i = 0; i < 8; i++) {
        try { pq.tuket(); Thread.sleep(250); }
        catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}, "Consumer");

producer.start();
consumer.start();

Deadlock — Kilitlenme

İki veya daha fazla thread birbirinin tuttuğu kilidi beklediğinde oluşan döngüsel bekleme durumudur. Dört Coffman koşulunun aynı anda sağlanması gerekir: Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait. Bunlardan herhangi birini kırarak deadlock önlenir.

JAVA Deadlock örneği ve çözümü (lock sıralaması) 
// ── Deadlock oluşturan KOD (❌ YANLIŞ) ────────────
class DeadlockOrnek {
    private static final Object LOCK_A = new Object();
    private static final Object LOCK_B = new Object();

    static void thread1() {
        synchronized (LOCK_A) {              // A'yı al
            try { Thread.sleep(100); }
            catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            synchronized (LOCK_B) {          // B'yi bekle → ÖLÜM!
                System.out.println("Thread1: A+B");
            }
        }
    }

    static void thread2() {
        synchronized (LOCK_B) {              // B'yi al
            try { Thread.sleep(100); }
            catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            synchronized (LOCK_A) {          // A'yı bekle → ÖLÜM!
                System.out.println("Thread2: B+A");
            }
        }
    }
}

// ── Çözüm: tutarlı lock sıralaması (✅ DOĞRU) ────
// Her iki thread de her zaman A → B sırasıyla kilitlesin
static void thread1Duzeltilmis() {
    synchronized (LOCK_A) {
        synchronized (LOCK_B) {
            System.out.println("Thread1: A→B (güvenli)");
        }
    }
}

static void thread2Duzeltilmis() {
    synchronized (LOCK_A) {    // ← artık A'yı ÖNCE alıyor
        synchronized (LOCK_B) {
            System.out.println("Thread2: A→B (güvenli)");
        }
    }
}

GC Nedir, Neden Gerekli?

Java'da bellek yönetimi geliştiricinin sorumluluğunda değildir. JVM'in Garbage Collector'ı, Heap'teki artık erişilemeyen nesneleri otomatik olarak tespit edip siler. Bu sayede manual free() / delete gibi C/C++ pratiklerine gerek kalmaz; ancak GC'nin ne zaman çalışacağını kontrol etmek mümkün değildir.

Heap Bölgeleri

Young Generation: Eden + Survivor (S0/S1). Yeni nesneler burada doğar, minor GC sık çalışır.

Old (Tenured) Generation: Uzun yaşayan nesneler. Major GC daha seyrek, daha maliyetli.

Metaspace (Java 8+): Sınıf metadata'sı; PermGen'in yerini aldı.

GC Algoritmaları

Serial GC: Tek thread, küçük uygulamalar.

Parallel GC: Çok thread, throughput odaklı (Java 8 default).

G1 GC: Region bazlı, dengeli; Java 9+ default.

ZGC / Shenandoah: Düşük gecikme, büyük heap'ler için.

Reachability (Erişilebilirlik Seviyeleri)

GC bir nesneyi toplamadan önce ona olan referansın gücüne bakar. java.lang.ref paketi dört farklı referans türü sunar.

Referans Türü Sınıf GC Davranışı Kullanım Amacı
Strong Normal değişken Referans varken asla toplanmaz Her normal nesne kullanımı

Wildcards (? , ? extends T, ? super T) & PECS Kuralı

Wildcard (joker karakter) ?, bilinmeyen bir tipi temsil eder. Üç farklı şekilde kullanılır:

  • Unbounded Wildcard (?): Herhangi bir tipi temsil eder (örn. List<?>). Sadece Object sınıfının metotlarını kullanabileceğimiz, okuma amaçlı kullanımlarda uygundur.
  • Upper Bounded Wildcard (? extends T): T tipini ya da T'den türetilmiş (alt) bir sınıfı temsil eder. Covariance (eşdeğişkenlik) sağlar.
  • Lower Bounded Wildcard (? super T): T tipini ya da T'nin üst sınıflarından (ata) birini temsil eder. Contravariance (karşıt değişkenlik) sağlar.
💡

PECS Kuralı (Producer Extends, Consumer Super): Eğer generic bir yapıdan veri okuyorsanız (veri üretiyorsa - producer), ? extends T kullanın (sadece okuma yapılabilir, yazma yapılamaz). Eğer generic bir yapıya veri yazıyorsanız (veri tüketiyorsa - consumer), ? super T kullanın (yazma yapılabilir, okumada ise geriye Object döner).

JAVA PECS kuralı ile liste elemanlarını kopyalama 
import java.util.*;

public class KoleksiyonYardimcisi {
    // PECS: kaynak liste veri üretiyor (extends), hedef liste veri tüketiyor/yazıyor (super)
    public static <T> void kopyala(List<? extends T> kaynak, List<? super T> hedef) {
        for (T eleman : kaynak) {
            hedef.add(eleman); // Hedefe güvenle yazabiliriz
        }
    }
}

// Kullanım
List<Integer> sayilar = List.of(1, 2, 3);
List<Number> numaralar = new ArrayList<>();

// Integer, Number'ın alt sınıfıdır (T = Number).
// List<Integer> (extends Number) -> List<Number> (super Number) kopyalama sorunsuz çalışır.
KoleksiyonYardimcisi.kopyala(sayilar, numaralar);
Type Erasure (Tip Silinmesi)

Java'da generics, geriye dönük uyumluluk sağlamak amacıyla yalnızca derleme zamanında (compile-time) mevcuttur. Derleyici, kodun tip güvenliğini doğruladıktan sonra tüm generic tip bilgilerini siler (erasure).

Kural / Sınır Derleme Sırasındaki İşlem (Type Erasure)
Sınırlandırılmamış tipler (<T>) Object tipine dönüştürülür.
Sınırlandırılmış tipler (<T extends Number>) İlk sınıra (örn. Number) dönüştürülür.
Tip dönüşümleri (Casting) İhtiyaç duyulan yerlere otomatik tür dönüşümü (cast) eklenir.

Sınıfların yüklenmesiyle birlikte sembolik referansların, sabitlerin (primitif sayılar ve String sabitleri) tutulduğu tablodur. Collectors (toList · toMap · groupingBy · joining)

collect() terminal işlemi stream'i istenen veri yapısına toplar. Collectors sınıfı hazır fabrika metotları sağlar.

JAVA Collectors – toList, toSet, toMap, groupingBy, joining, partitioningBy 
import java.util.stream.Collectors;

record Urun(String ad, String kategori, double fiyat) {}

List<Urun> urunler = List.of(
    new Urun("Elma",  "Meyve",  5.0),
    new Urun("Muz",   "Meyve",  7.5),
    new Urun("Havuç", "Sebze",  3.0),
    new Urun("Kiraz", "Meyve", 12.0),
    new Urun("Patlıcan", "Sebze", 4.5)
);

// ── toList / toSet ───────────────────────────────
List<String> adlar = urunler.stream()
    .map(Urun::ad)
    .collect(Collectors.toList());

// ── toMap: ad → fiyat ────────────────────────────
Map<String, Double> fiyatHaritasi = urunler.stream()
    .collect(Collectors.toMap(Urun::ad, Urun::fiyat));
System.out.println(fiyatHaritasi.get("Kiraz"));  // 12.0

// ── groupingBy: kategoriye göre grupla ───────────
Map<String, List<Urun>> kategoriler = urunler.stream()
    .collect(Collectors.groupingBy(Urun::kategori));
// {Meyve=[Elma, Muz, Kiraz], Sebze=[Havuç, Patlıcan]}

// groupingBy + downstream: her kategorinin toplam fiyatı
Map<String, Double> kategoriToplam = urunler.stream()
    .collect(Collectors.groupingBy(
        Urun::kategori,
        Collectors.summingDouble(Urun::fiyat)
    ));
System.out.println(kategoriToplam);  // {Meyve=24.5, Sebze=7.5}

// ── partitioningBy: koşula göre ikiye böl ────────
Map<Boolean, List<Urun>> bolunmus = urunler.stream()
    .collect(Collectors.partitioningBy(u -> u.fiyat() > 5));
System.out.println(bolunmus.get(true));   // [Muz, Kiraz]
System.out.println(bolunmus.get(false));  // [Elma, Havuç, Patlıcan]

// ── joining: String'leri birleştir ───────────────
String sonuc = urunler.stream()
    .map(Urun::ad)
    .collect(Collectors.joining(", ", "[", "]"));
System.out.println(sonuc);  // [Elma, Muz, Havuç, Kiraz, Patlıcan]

// ── counting: grup başına eleman sayısı ──────────
Map<String, Long> grupAdet = urunler.stream()
    .collect(Collectors.groupingBy(
        Urun::kategori, Collectors.counting()));
System.out.println(grupAdet);  // {Meyve=3, Sebze=2}
Optional — null'dan Kaçınmak

Optional<T>, bir değerin var veya yok olabileceğini ifade eden kap sınıfıdır. Stream terminal işlemlerinin birçoğu (findFirst, min, max, reduce) Optional döndürür; null kontrolü yerine kullanılır.

JAVA Optional – oluşturma, sorgulama, zincirleme 
import java.util.Optional;

// ── Oluşturma ────────────────────────────────────
Optional<String> dolu = Optional.of("Java");        // null geçilirse NPE
Optional<String> bos  = Optional.empty();
Optional<String> bel  = Optional.ofNullable(belkiNull());  // null olabilir

// ── Sorgulama ────────────────────────────────────
System.out.println(dolu.isPresent());              // true
System.out.println(bos.isEmpty());                // true (Java 11+)
dolu.ifPresent(System.out::println);               // "Java"

// ── Değer alma ───────────────────────────────────
String v1 = bos.orElse("default");                // "default"
String v2 = bos.orElseGet(() -> hesapla());       // lazy, sadece gerekirse çağrılır
String v3 = bos.orElseThrow(() ->
    new IllegalStateException("Değer yok"));        // yok → exception

// ── map / flatMap / filter ile zincirleme ─────────
Optional<String> buyuk = dolu
    .filter(s -> s.length() > 3)
    .map(String::toUpperCase);
System.out.println(buyuk.orElse("kısa"));           // "JAVA"

// ── or(): Java 9+ – boşsa başka Optional dön ─────
Optional<String> yedek = bos.or(() -> Optional.of("yedek"));

// ── ifPresentOrElse(): Java 9+ ────────────────────
bos.ifPresentOrElse(
    v -> System.out.println("Değer: " + v),
    () -> System.out.println("Değer yok")
);
⚠

Parallel Stream

.parallelStream() veya .parallel() çağrısıyla stream ForkJoinPool üzerinde çok çekirdekli çalışır. Her durumda hız artışı sağlamaz; veri kümesi küçükse thread yönetimi maliyeti overhead yaratır.

Parallel Uygun Parallel Uygun Değil
Büyük veri kümesi (> 10.000 eleman) Küçük koleksiyonlar
CPU-yoğun bağımsız işlemler Sıra önemli operasyonlar (findFirst gibi)
reduce, filter, map kombinasyonları Shared mutable state (race condition riski)
JAVA parallelStream – kullanım ve dikkat edilecekler 
import java.util.stream.IntStream;

// ── Paralel toplama ──────────────────────────────
long toplam = IntStream.rangeClosed(1, 1_000_000)
    .parallel()             // artık paralel
    .asLongStream()
    .sum();
System.out.println(toplam);  // 500000500000

// ── Koleksiyon üzerinde ──────────────────────────
List<String> buyukListe = /* ... binlerce eleman ... */ new ArrayList<>();
List<String> filtrelenmis = buyukListe.parallelStream()
    .filter(s -> s.length() > 5)
    .collect(Collectors.toList());  // thread-safe collector

// ── ❌ YANLIŞ: Shared mutable state ──────────────
List<Integer> hataListe = new ArrayList<>();
IntStream.range(0, 1000).parallel().forEach(hataListe::add);  // race condition!

// ── ✅ DOĞRU: collect ile topla ─────────────────
List<Integer> guvenli = IntStream.range(0, 1000)
    .parallel()
    .boxed()
    .collect(Collectors.toList());  // güvenli

Lombok Kütüphanesi

Lombok, derleme aşamasında (compile-time) çalışan bir annotation processor kütüphanesidir. Sınıflara eklenen basit annotasyonlar sayesinde Java'daki tekrarlayan (boilerplate) kodları (getter, setter, constructor, toString vb.) otomatik olarak üretir ve kod tabanını sadeleştirir.

ℹ

Temel Lombok Annotasyonları:
• @Getter / @Setter: Alanlar için otomatik erişim metotları üretir.
• @ToString: Sınıf alanlarını içeren anlamlı bir toString() metodu oluşturur.
• @RequiredArgsConstructor: final alanları parametre alan bir constructor yazar.
• @Data: Getter, Setter, RequiredArgsConstructor, ToString, EqualsAndHashCode annotasyonlarının tamamını tek seferde ekleyen kombinasyondur.
• @Builder: Nesne oluştururken akıcı (fluent) arayüz sunan Builder Tasarım Kalıbını uygular.
• @Slf4j: Sınıf içerisine otomatik olarak log isimli bir SLF4J logger nesnesi enjekte eder.

JAVA Lombok annotasyonları ve Builder kullanımı 
import lombok.Data;
import lombok.Builder;
import lombok.extern.slf4j.Slf4j;

@Data
@Builder
@Slf4j
public class KullaniciKayit {
    private final String eposta;     // final olduğu için constructor'a dahil edilir
    private String adSoyad;
    private int yas;

    public static void main(String[] args) {
        // 1. Builder ile akıcı şekilde nesne oluşturma
        KullaniciKayit user = KullaniciKayit.builder()
            .eposta("kutay@example.com")
            .adSoyad("Kutay Şen")
            .yas(25)
            .build();

        // 2. @Data ile üretilen getter metodu
        String isim = user.getAdSoyad();

        // 3. @Slf4j ile üretilen log nesnesi kullanımı
        log.info("Yeni kullanıcı kaydedildi: {}, Adı: {}", user, isim);
    }
}

JAVA Apache Commons Lang3 & IO – örnekler 
import org.apache.commons.lang3.StringUtils;
import org.apache.commons.lang3.math.NumberUtils;
import org.apache.commons.io.FileUtils;

// ── StringUtils: Null-safe string işlemleri ───────────
StringUtils.isBlank("  ");           // true (boşluk da blank sayılır)
StringUtils.isBlank(null);           // true (NPE fırlatmaz!)
StringUtils.defaultIfBlank(null, "N/A");  // "N/A"
StringUtils.capitalize("java");       // "Java"
StringUtils.reverse("merhaba");     // "abahrem"
StringUtils.abbreviate("Uzun bir metin", 10);  // "Uzun b..."

// ── NumberUtils: Güvenli sayı dönüşümleri ─────────────
NumberUtils.toInt("42");             // 42
NumberUtils.toInt("abc", 0);         // 0 (exception yerine default)
NumberUtils.isParsable("3.14");      // true

// ── FileUtils: Basitleştirilmiş dosya işlemleri ──────
File dosya = new File("/tmp/test.txt");
