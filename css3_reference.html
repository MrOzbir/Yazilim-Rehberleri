CSS3 Kapsamlı Başvuru Rehberi

Modern web tasarımının kalbi olan CSS3 için derinlemesine teknik detaylar, best-practiceler, mimari yapılar ve ileri düzey konseptler referansı.

01. CSS Seçiciler & Öncelik Sıralaması (Specificity)

CSS seçiciler, DOM üzerindeki spesifik elementleri hedeflememizi sağlayan kurallar bütünüdür. Specificity ise, aynı elementi hedefleyen birden fazla kural olduğunda hangi kuralın ezici olacağını belirleyen puanlama sistemidir.

Temel ve Nitelik Seçiciler

Elementleri etiketine, sınıfına, kimliğine veya sahip olduğu niteliklere (attributes) göre seçebilirsiniz.

/* Evrensel Seçici */
* { margin: 0; padding: 0; }

/* Class ve ID Seçici */
.btn { color: white; }
#main-header { font-size: 2rem; }

/* Nitelik (Attribute) Seçicileri */
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; } /* https ile başlayanlar */
a[href$=".pdf"] { color: red; }    /* .pdf ile bitenler */
Kombinatörler (Combinators)

Elementler arasındaki hiyerarşik (ebeveyn-çocuk, kardeş) ilişkileri tanımlar.

/* Torun (Descendant) Seçici: Boşluk */
.card p { color: gray; } /* .card içindeki tüm p'ler */

/* Çocuk (Child) Seçici: > */
ul > li { list-style: none; } /* Sadece doğrudan alt öğe olan li'ler */

/* Bitişik Kardeş (Adjacent Sibling): + */
h2 + p { margin-top: 0; } /* h2'den hemen sonra gelen ilk p */

/* Genel Kardeş (General Sibling): ~ */
h2 ~ p { font-size: 1.1rem; } /* h2 ile aynı seviyedeki tüm p'ler */
Specificity (Öncelik Puanlaması)

Tarayıcılar çakışan kuralları çözerken (Inline, ID, Class, Element) şeklindeki 4 haneli puanlamaya bakar.

Puanlama Tablosu
  • Inline Stiller: (1,0,0,0) - 1000 Puan
  • ID Seçiciler (#): (0,1,0,0) - 100 Puan
  • Class, Nitelik ve Pseudo-class: (0,0,1,0) - 10 Puan
  • Element ve Pseudo-element: (0,0,0,1) - 1 Puan
!important Tehlikesi
!important bu puanlamayı tamamen yok sayarak en yüksek önceliği alır. Sadece utility (yardımcı) sınıflarda veya 3. parti kütüphaneleri ezerken dikkatli kullanılmalıdır, aksi takdirde CSS mimarinizi kırılganlaştırır.
Kalıtım (Inheritance)

Bazı CSS özellikleri (örneğin font-family, color) ebeveynden çocuk elementlere otomatik geçer. Kalıtımı yönetmek için özel değerler kullanılır.

.child {
  /* Ebeveyndeki değeri zorla miras alır */
  color: inherit; 
  
  /* Tarayıcının varsayılan ilk değerine döner */
  border: initial; 
  
  /* Kalıtsal bir özellikse 'inherit', değilse 'initial' gibi davranır */
  margin: unset; 
}

02. Kutu Modeli (Box Model) & Sınırlar

CSS'te HTML'deki her element görünmez bir dikdörtgen kutu olarak ele alınır. Bu kutunun anatomisini anlamak, doğru boyutlandırma ve boşluklandırma yapabilmenin tek yoludur.

Kutu Anatomisi

Bir element dıştan içe doğru 4 katmandan oluşur:

  • Margin: Elementin çevresindeki görünmez dış boşluk.
  • Border: Padding ve Content etrafındaki görünür sınır.
  • Padding: İçerik ile border arasındaki iç boşluk.
  • Content: Metnin veya resmin bulunduğu asıl (width/height) alan.
box-sizing Stratejisi

Varsayılan content-box modelinde padding ve border, elementin genişliğine (width) eklenir ve elementi büyütür. Endüstri standardı olan border-box ise bunları genişliğin içine dahil eder.

/* Evrensel Border-Box Reset (Modern Standart) */
*, *::before, *::after {
  box-sizing: border-box;
}

.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  /* border-box ile bu kutu tam 200px kalır. 
     İçerik alanı 150px'e (200-40-10) daralır. */
}
Margin Collapse (Çökme) Sendromu

Blok seviyesindeki ardışık iki elementin dikey margin (top/bottom) değerleri karşılaştığında, toplamları alınmaz; sadece büyük olan margin değeri uygulanır (çöker).

Çözüm Yolları
Margin çökmesini engellemek için elementlerin bir BFC (Block Formatting Context) içinde olması veya aralarında padding/border/inline içerik bulunması gerekir. Günümüzde display: flex veya display: grid kullanarak margin çökmesi sendromundan tamamen kurtulabilirsiniz.
Outline vs Border

outline (dış hat), border'a benzese de kutu modelinin boyutlarına dahil edilmez (yer kaplamaz) ve elementin dışından çizilir.

.input-field {
  border: 1px solid #ccc;
}

.input-field:focus {
  /* Genellikle erişilebilirlik (a11y) için kullanılır, 
     sayfa düzenini bozmadan odak (focus) halkası çizer. */
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}

03. Ekran Düzenleri (Display & Positioning)

Elementlerin sayfa akışında nasıl davranacağını ve nereye konumlandırılacağını belirleyen temel yerleşim teknikleri.

Display Değerleri
.element {
  /* Tüm satırı kaplar, margin/padding her yönde çalışır. (Örn: div, p, h1) */
  display: block; 
  
  /* Sadece içeriği kadar yer kaplar. margin-top/bottom ÇALIŞMAZ. (Örn: span, a) */
  display: inline; 
  
  /* Yan yana dizilir ama block gibi boyut (width/height/margin) verilebilir. */
  display: inline-block; 
  
  /* Elementi DOM'dan görsel olarak siler, yer kaplamaz. */
  display: none; 
}

.hidden-element {
  /* Elementi gizler AMA kapladığı boşluk sayfada kalır. */
  visibility: hidden; 
}
Positioning (Konumlandırma) Kuralları

Sayfa akışını (document flow) manipüle etmek için position kullanılır.

  • static: Varsayılan değer. Normal akışta kalır. top/left/z-index etki etmez.
  • relative: Normal akıştaki yerine göre kaydırılır. Akışta bıraktığı boşluk korunur.
  • absolute: Akıştan tamamen çıkarılır (havaya kalkar). static olmayan en yakın ebeveynine göre hizalanır.
  • fixed: Akıştan çıkarılır ve doğrudan viewport'a (tarayıcı penceresine) sabitlenir. Scroll edilse de kıpırdamaz.
  • sticky: Relative ve Fixed karışımıdır. Element, belirlenen bir scroll noktasına gelene kadar relative, sonrasında viewport içinde kalacak şekilde fixed davranır.
Absolute & Relative İlişkisi

Absolute elementi belirli bir kutunun içinde tutmanın en yaygın senaryosu.

.parent-container {
  /* Absolute çocuğun referans alacağı koordinat düzlemini başlatır */
  position: relative; 
}

.child-badge {
  position: absolute;
  top: 10px;
  right: 10px;
  /* parent-container'ın sağ üst köşesine yapışır */
}
Z-Index & Stacking Context

Z-ekseninde (derinlik) hangi elementin üstte görüneceğini belirler.

Stacking Context (Yığınlama Bağlamı)
Z-index değeri sadece position değeri static olmayan elementlerde veya Flex/Grid çocuklarında çalışır. Yeni bir yığınlama bağlamı oluşan elementlerde (örn: opacity < 1, transform, filter), içerdeki elementin z-index'i ne kadar büyük olursa olsun dışarıdaki elementin z-index sınırını geçemez.

04. Modern Düzenler: Flexbox & Grid

Günümüz web tasarımında düzenleri inşa etmenin en güçlü ve endüstri standardı iki mekanizması Flexbox ve CSS Grid'dir.

Flexbox (Esnek Kutu Modeli)

1-Boyutlu (Tek satır veya tek sütun) yerleşimlerde mükemmeldir. İçeriklerin hizalanması, boşlukların dağıtılması ve esnek büyüme/küçülme davranışları sağlar.

.flex-container {
  display: flex;
  flex-direction: row; /* row (yan yana) | column (alt alta) */
  justify-content: space-between; /* Ana eksende hizalama */
  align-items: center; /* Çapraz eksende hizalama */
  flex-wrap: wrap; /* Sığmayanlar alta insin */
  gap: 1.5rem; /* Öğeler arası boşluk */
}

.flex-item {
  /* flex: [grow] [shrink] [basis] */
  /* Büyüme izni var, küçülme izni var, ideal boyutu 200px */
  flex: 1 1 200px; 
}
CSS Grid (Izgara Sistemi)

2-Boyutlu (Aynı anda hem satır hem sütun) yerleşimleri kusursuz yönetir. Karmaşık sayfa iskeletleri ve makro layout'lar için idealdir.

.grid-container {
  display: grid;
  /* 3 sütunlu yapı: ilk ikisi 1 parça (fr), sonuncusu en az 250px en çok 1 parça */
  grid-template-columns: repeat(2, 1fr) minmax(250px, 1fr);
  grid-template-rows: auto 1fr; 
  gap: 20px;
}

.grid-item {
  /* Bu öğe 1. sütundan başlayıp 3. sütuna kadar (toplam 2 sütun) genişler */
  grid-column: 1 / 3; 
  grid-row: 1;
}
Grid Area Kullanımı

CSS Grid ile çok net ve okunabilir sayfa yapıları tasarlayabilirsiniz.

.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
Hangisini Tercih Etmeli?
1D vs 2D Kuralı
  • Flexbox: İçerik (content-first) odaklıdır. Bir navbar içindeki linkleri hizalamak, buton içindeki ikonu ve metni ortalamak veya yan yana esnek kartlar dizmek için kullanın.
  • CSS Grid: Düzen (layout-first) odaklıdır. Sayfanın genel iskeletini (header, sidebar, content) oluşturmak veya tam olarak iki boyutlu, hizalı ızgara tabanlı galeriler yapmak için kullanın.

05. Renkler, Arka Planlar & Gradyanlar

CSS'te renk uzayları ve arka plan yönetiminin temelleri ile estetik gradyan tasarımları.

Renk Formatları
.element {
  color: #ff5733;            /* HEX: Alfa desteği 8 hanelidir (#ff573380) */
  color: rgb(255, 87, 51);   /* RGB: Sabit renk kodları */
  color: rgba(0, 0, 0, 0.5); /* RGBA: Alfa (saydamlık) destekli */
  color: hsl(120, 100%, 50%);  /* HSL: Ton, Doygunluk, Parlaklık (Responsive renkler için ideal) */
  color: hsla(120, 50%, 50%, 0.8); /* HSLA: HSL + Saydamlık */
}
Arka Plan Görselleri
.hero-bg {
  background-image: url('/img/hero.jpg');
  background-size: cover; /* Resmi, orantısını koruyarak alanı kaplayacak şekilde ölçekler */
  /* Diğer boyutlar: contain (tamamını sığdır), auto */
  background-position: center; /* Resmi merkeze hizalar */
  background-repeat: no-repeat; /* Döşemeyi engeller */
}
Gradyanlar (Gradients)
.gradient-box {
  /* Doğrusal Gradyan: 135 derece açıyla soldan sağa */
  background: linear-gradient(135deg, var(--accent), var(--cyan));
  
  /* Radyal Gradyan: Merkezden dışa doğru yayılan dairesel renk */
  background: radial-gradient(circle, #fff, #333);
}

06. Tipografi & Metin Özellikleri

Okunabilirlik (Readability) ve genel estetiği sağlayan tipografi ve text stillendirmesi.

Yazı Tipi ve Boyutlar
.text {
  font-family: 'Inter', sans-serif;
  
  /* px: Sabit pikseller. em: Ebeveyne göre. rem: Kök (html) elementine göre oranlanır. */
  font-size: 1.2rem; 
  
  font-weight: 600; /* 100-900 arası değer alır (400=normal, 700=bold) */
  line-height: 1.5; /* Satır yüksekliği (1.5 katı) */
  letter-spacing: -0.02em; /* Harfler arası boşluk daraltması */
}
Metin Düzeni ve Gölgeler
.heading {
  text-align: center; /* left, right, justify, center */
  
  /* text-shadow: yatay-x dikey-y bulanıklık-blur renk */
  text-shadow: 2px 4px 6px rgba(0, 0, 0, 0.3);
  
  text-transform: uppercase; /* uppercase, lowercase, capitalize */
}

07. Dönüşümler & Geçişler (Transforms & Transitions)

GPU üzerinde donanımsal hızlandırma ile performanslı mikro-etkileşimler yaratma kuralları.

2D ve 3D Transforms
.box {
  /* X ekseninde 50px sağa, Y ekseninde 20px aşağı taşı */
  transform: translate(50px, 20px); 
  
  /* 45 derece döndür */
  transform: rotate(45deg); 
  
  /* Yüzde 20 büyüt */
  transform: scale(1.2); 
  
  /* X ekseninde yamult */
  transform: skewX(10deg); 
  
  /* 3D Transform: Derinlik (Z) ekseninde döndür ve taşı */
  transform: perspective(500px) rotateY(30deg) translateZ(50px);
}
Geçişler (Transitions)
.btn {
  background: blue;
  
  /* transition: [özellik] [süre] [zamanlama-fonk] [gecikme] */
  transition: background 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.btn:hover { background: darkblue; }
Performans Bilgisi
Tarayıcıyı yormamak için geçişlerde (Repaint veya Reflow tetikleyen) width, height, top, left yerine transform ve opacity kullanmalısınız.

08. CSS Animasyonları (Keyframes)

Elementlerin başlangıçtan bitişe karmaşık zaman tünelleri (timeline) oluşturarak hareketlendirilmesi.

@keyframes Tanımlama
@keyframes slideIn {
  0% {
    transform: translateX(-100%);
    opacity: 0;
  }
  100% {
    transform: translateX(0);
    opacity: 1;
  }
}
Animasyonu Uygulama & Optimizasyon
.animated-box {
  /* name | duration | timing-function | delay | iteration-count | direction | fill-mode */
  animation: slideIn 0.5s ease-out 0s 1 normal forwards;
  
  /* GPU Acceleration'ı zorla tetiklemek için optimizasyon (Eski Yöntem) */
  /* transform: translateZ(0); */
  
  /* Modern Optimizasyon: Tarayıcıya önceden haber verir */
  will-change: transform, opacity;
}

09. Responsive Tasarım & Media Queries

Gelişmiş ekran boyutlarına dinamik olarak uyum sağlama sanatıdır.

Mobil-Öncelikli (Mobile-First) Mimari

Kodun varsayılan hali mobildir, ekran büyüdükçe (min-width) yeni özellikler eklenir. Bu, mobil cihazları gereksiz masaüstü CSS'lerini okumaktan kurtarır.

/* Tüm cihazlar (Mobil varsayılan) */
.layout { display: flex; flex-direction: column; }

/* Tablet ve Üzeri Breakpoint */
@media (min-width: 768px) {
  .layout { flex-direction: row; }
}

/* Sadece Küçük Ekranlara Özel (Tavsiye Edilmez) */
@media (max-width: 500px) { ... }

10. CSS Değişkenleri (Custom Properties) & Fonksiyonlar

CSS içinde matematiksel hesaplamalar ve dinamik değer atamaları.

Değişkenler (Custom Properties)
:root {
  --primary-color: #3498db;
  --spacing: 16px;
}
.box {
  color: var(--primary-color);
  padding: var(--spacing);
}
Matematik ve Dinamik Fonksiyonlar
.container {
  /* calc: Birimler arası matematik hesabı */
  width: calc(100% - 40px);
  
  /* clamp: min-değer, ideal-değer, max-değer (Tipografide çok kullanılır) */
  font-size: clamp(1rem, 2vw + 0.5rem, 2.5rem);
  
  /* min/max: İki değerden küçüğünü veya büyüğünü seçer */
  max-width: min(900px, 100%);
}

11. Pseudo-classes & Pseudo-elements

Elementlerin belirli durumlarını veya DOM'da fiziksel olarak olmayan sahte öğelerini hedefleme.

Durum (State) Seçicileri
.btn:hover { background: darkblue; }   /* Fare üzerine geldiğinde */
.input:focus { border-color: blue; }   /* Klavye veya fare ile odaklandığında */
.btn:active { transform: scale(0.9); } /* Tıklandığı an */

/* nth-child: Belirli sıradaki kardeş öğeleri seçer (Örn: Çift sıralar) */
li:nth-child(even) { background: #eee; }

/* :not(): Belirtilen seçici hariç hepsini hedefler */
.card:not(.active) { opacity: 0.5; }
Sanal Elementler (::before & ::after)
Content Zorunluluğu
::before ve ::after kullanırken ekranda belirmeleri için mutlaka boş da olsa content: ""; özelliğini tanımlamanız gerekir. Bu elementler genelde estetik arka plan dekorları (çiçek, ok, gölge vb.) için kullanılır.

12. Tarayıcı Performansı & Modern CSS Mimarileri

Render bloklamalarını kaldırma ve CSS kodunu ölçeklenebilir bir mimariyle yazma teorileri.

Repaint ve Reflow (Tarayıcı Yükü)
  • Reflow: Elementin boyutu, margin'i, genişliği (width/height) değiştiğinde tarayıcının tüm sayfadaki elementlerin konumunu yeniden hesaplaması. (Çok Maliyetli)
  • Repaint: Elementin rengi, gölgesi gibi görsel (fiziksel boyutunu etkilemeyen) kısımları değiştiğinde ekrana yeniden çizilmesi. (Nispeten daha az maliyetli)
BEM (Block, Element, Modifier)

Spagetti koda ve specificity savaşlarına son vermek için kullanılan isimlendirme konvansiyonu.

/* Block (Kapsayıcı Bileşen) */
.card { ... }

/* Element (Bileşenin iç parçası) (Çift alt çizgi) */
.card__title { ... }
.card__image { ... }

/* Modifier (Bileşenin varyasyonu) (Çift tire) */
.card--featured { border: 2px solid gold; }
